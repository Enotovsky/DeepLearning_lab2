# Новая версия: исходные фотографии без изменения разрешения

Запустите `main_original.py` в PyCharm кнопкой Run или из PowerShell:

```powershell
.\.venv\Scripts\python.exe main_original.py
```

Программа выводит ответы двух сетей для фотографии и открывает окно с этой фотографией и ответами. Закройте окно, чтобы перейти к следующему снимку. Всего 10 снимков и 20 проверяемых предсказаний. При запуске из PyCharm, если картинки открываются во встроенной панели и выполнение не останавливается, отключите опцию показа графиков в окне инструментов (Show plots in tool window) в настройках Python Plots/Scientific.

Исходники находятся в `data_original`. Ответы и итоговое сравнение выводятся только в консоль. Картинки открываются в окнах Matplotlib. Программа не создаёт отчёт и не сохраняет изображения. Старый `main.py`, его фотографии и результаты сохранены; файлы в `results_original` остались от предыдущих запусков и больше не обновляются.

Выбрано по два разных снимка пяти классов: линь, спрингер-спаниель, церковь, мусоровоз и парашют. На одном объект занимает большую часть кадра, на другом меньшую. «Крупный/общий план» — визуальная оценка, реальное расстояние неизвестно. Список файлов исходного архива находится в `data_original/sources.txt`.

Фотографии взяты без перекодирования из уже скачанного набора Imagenette160. Сам набор предоставлен в уменьшенной версии его авторами; программа сохраняет файлы из этого набора без изменения. Это разные размеры готовых файлов, а не оригиналы полного разрешения с камеры.

В обработке нет Resize, Crop, добавления фона или изменения масштаба. Только RGB, ToTensor и Normalize. Тензор имеет форму `[1, 3, исходная высота, исходная ширина]`. Проверка assert подтверждает совпадение размеров. ResNet использует адаптивное усреднение признаков и может обрабатывать эти разные размеры без обязательного приведения к 224x224. Это отличается от стандартного режима оценки предобученных весов.

При показе Matplotlib подгоняет фотографию под экран; это не меняет вход сети.

Как объяснить преподавателю: «Я взял 10 разных фотографий с разной крупностью объектов и разными исходными размерами файлов. Размеры в программе не меняются. На каждой фотографии сравнил ResNet18 и ResNet152 с весами ImageNet V1. Вывожу изображение, ответ, уверенность и время, проверяю ответ по известному классу. Итоги выводятся в консоль. Поскольку снимки разные, на результат влияет не только крупность объекта, но и фон, ракурс и освещение».
