# DeepLearning_lab2 — сравнение ResNet18 и ResNet152

Лабораторная работа: распознавание 10 фотографий с разной крупностью объектов и исходными размерами. Модели выполняются на CPU с готовыми весами ImageNet V1, без обучения.

## Установка и запуск

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main_original.py
```

При первом запуске нужен интернет для загрузки весов ResNet18 и ResNet152 (~280 МБ). Они сохраняются в `data/torch` и в Git не включены. Дальнейшие запуски работают без интернета. Python должен включать Tkinter для окон Matplotlib.

## Основная версия — main_original.py

- 10 фотографий: по два снимка рыбы, собаки, церкви, мусоровоза и парашюта.
- Разрешение фотографий не меняется: только преобразование в RGB, тензор и нормализация ImageNet.
- Для каждого снимка выводятся ответы обеих сетей, уверенность, правильность и время вызова на CPU.
- Открывается окно с фотографией и ответами. Закройте его, чтобы перейти к следующему снимку.
- Итоговое сравнение выводится в консоль. Отчёты и картинки в файлы не сохраняются.

Подробнее: [объяснение основной версии](README_original.md).

## Сохранённая старая версия — main.py

```powershell
.\.venv\Scripts\python.exe main.py
```

Имитирует три масштаба, помещая каждую из 10 фотографий на фон 224x224. Выводит ответы в консоль и создаёт `results/report.md`. Описание: [README_legacy.md](README_legacy.md).

## Структура

- `data_original/` — исходные фотографии основной версии и список источников.
- `data/*.jpeg` — фотографии старой версии.
- `requirements.txt` — зависимости; `requirements-lock.txt` — версии среды разработки.
- Виртуальная среда, настройки IDE, веса, архивы и результаты запусков исключены через `.gitignore`.

## Ограничения и источники

Фотографии взяты из готовой версии [Imagenette160](https://github.com/fastai/imagenette), предоставленной авторами в уменьшенном разрешении. Исходные файлы этой версии сохранены без перекодирования. Их пути перечислены в `data_original/sources.txt`. Права на фотографии принадлежат соответствующим правообладателям.

«Крупный/общий план» — визуальная оценка, расстояние до камеры неизвестно. Разные снимки отличаются также фоном, ракурсом и освещением. Всего пять примеров на план, поэтому эксперимент не позволяет выделить влияние только расстояния и не определяет качество моделей в целом.

Архитектуры и веса предоставлены [TorchVision](https://docs.pytorch.org/vision/stable/models/resnet.html). Размер входа различается; он не приводится к стандартной геометрии оценки предобученных весов. Время измеряется одним вызовом после прогрева.
